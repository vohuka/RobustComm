# Examples

Small, offline examples. All outputs are synthetic smoke-test outputs, not paper results.

## Quick example run
```bash
python scripts/run_experiment.py --config examples/example_config.yaml --stage all
python scripts/make_plots.py --input outputs/example --output outputs/example/plots
```

## Example synthetic dataset
`synthetic_data/example_messages.csv` is a tiny message table generated by
`robustcomm.data.generate_message_rounds` (schema in `docs/data_format.md`). Regenerate it:
```bash
python -c "from robustcomm.data import generate_message_rounds; \
generate_message_rounds(n_rounds=10, n_senders=9, msg_dim=4, n_byzantine=2, seed=0)\
.to_csv('examples/synthetic_data/example_messages.csv', index=False)"
```
(Run from the repo root with `src/` on `PYTHONPATH`, or after `pip install -e .`.)

## Inspect the theoretical bounds
```bash
python -m robustcomm.cli theory --operator krum --n 9 --f 2 --d 4 --B 0.5
python -m robustcomm.cli theory --operator median --n 9 --f 4 --d 4 --B 0.5
```
